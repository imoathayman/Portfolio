# Moath Ayman — حزمة الهوية الشخصية (Personal Brand Identity)

هذه الحزمة توثّق الهوية البصرية والشخصية الكاملة، لتكون مرجعاً واحداً موحّداً عند بناء أي مادة جديدة (موقع، سيرة ذاتية، بطاقة عمل، محتوى تسويقي...).

## الهيكلية

```
identity/
├── README.md                  (هذا الملف — الفهرس)
├── 00-overview.md              نظرة عامة: الجوهر، القيم، التاجلاين
├── 01-logo.md                  قواعد استخدام الشعار
├── 02-colors.md                بالتة الألوان الكاملة
├── 03-typography.md            الخطوط والأوزان
├── 04-voice-and-values.md      القيم ونبرة الصوت بالتفصيل
└── assets/
    ├── logo/
    │   ├── logo-primary.png    الشعار — نسخة للخلفيات الفاتحة
    │   └── logo-on-dark.png    الشعار — نسخة للخلفيات الغامقة
    └── board/
        └── brand-board.png     لوحة الهوية الشاملة (مرجع بصري)
```

## الخطوة التالية

هذه الحزمة توثّق **الهوية الشخصية**. الخطوة التالية هي بناء **هوية الموقع (Website Identity)** فوق هذا الأساس — تطبيق نفس النظام على مكونات واجهة فعلية (أزرار، بطاقات، أقسام) قبل البدء بتنفيذ الموقع نفسه بـ Vue 3 + Tailwind.
